# TableFlow Privacy Policy

TableFlow processes webpage table content locally inside the user's browser.

- No account is required.
- No browsing history is collected.
- No webpage content is transmitted to external servers.
- No personal data is sold or shared.
- Exported files are created only after a user action.

The extension requests `activeTab` and `scripting` to inspect tables on the currently active page after the user clicks the extension. It requests `downloads` only to save user-requested exports.

Contact information and effective date must be added before public release.
